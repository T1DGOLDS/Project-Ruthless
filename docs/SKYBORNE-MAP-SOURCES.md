# Skyborne world-map locations

RUI uses known location facts from Skyborne Ley Line & Convergence Marker (SLLCM) v0.3.1 by tr0tsky, file 9139279, uploaded October 11, 2026. Source: https://www.curseforge.com/wow/addons/sllcm/files/9139279. License: https://www.curseforge.com/wow/addons/sllcm/license. Download retained in the development workspace as work/sllcm-0.3.1.zip; no third-party addon was installed and no upstream sharing/network/auras/settings logic is imported.

Only location data is adapted. RUI's native canvas provider is independently implemented. Skyborne race token comes from the author's inspected UnitRace detection. Alliance receives ley-line pins; Horde receives elemental-convergence pins. Non-Skyborne characters receive none. Pins are passive known-location indicators with hover coordinates, not live availability claims, routes, connected lines or automation. RUI sends no messages and does not inspect buffs or cast racials. Zone-map coverage is bounded by the upstream known data, not every possible location. Native quest pins/blue areas remain untouched.
