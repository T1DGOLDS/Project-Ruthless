# Backgrounds and rested XP — beta70

Settings > Backgrounds supplies a 0–100% global background-only slider and sixteen separate override sliders: quest tracker, player, target, party, chat, action bars, XP/reputation, micro menu, bag buttons, open bags, meters, map/log, spellbook, cast/attack timers, settings/edit mode and professions. Disable an override to inherit, or use Reset all to global. Defaults inherit the existing rendered quest box opacity (at least 72% in previous builds). Preferences are account-wide and included in the settings-profile export/import format. Named layout profiles remain position/chat/art profiles, separate from account settings profiles.

Owned backdrop frames/textures receive opacity directly; text, icons, health/resource fills, native map tiles and objective pins are not faded. Colours and selection/hover accents remain independent. No per-frame polling is added. Action-bar containers no longer add a second shade underneath their buttons, portrait backing is transparent, and native meter backdrops are transparent behind the RUI surface. Adjacent/nested controls can still overlap; live rendering remains the acceptance check. Global control applies to RUI-styled backgrounds, not arbitrary third-party windows or every Blizzard window.

Rested XP uses public UnitXP / UnitXPMax / GetXPExhaustion. A flat blue-grey segment spans current XP to current XP plus bonus, clipped at the current level's edge; the tooltip displays the full numerical bonus, including overflow into later levels. Native exhaustion/XP updates and resizing refresh the segment, including combat. No rested amount, zero-size/max-XP, disabled XP, level cap or restricted values hide the segment. The old pip art and prediction fill are suppressed; native event ownership and hover tooltip remain. Rested fill is informational XP data and is not changed by the background-opacity slider.
