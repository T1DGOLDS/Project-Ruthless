# Quest map indicators

Native quest markers, turn-ins and blue objective areas retain game ownership. RUI supplements them with verified pickup locations and recorded unfinished objective sources. The selected objective stays linked to the main map.

Interaction objectives use a cog, creature loot objectives a bag and kill objectives a sword. Minimap markers are small, visual-only and omit completed, unknown or restricted objectives. Matching nameplate hints share the same icon vocabulary. Exact source coverage is limited to recorded facts; general kill areas do not receive invented pickup points.

The same-zone navigation header uses a recorded or native supplied destination. Unknown/cross-map directions are explained rather than guessed. No server death boundaries or quest-area polygons are inferred from the map artwork.

Source records and mandatory notices live beside the bundled data. Party progress/tooltips and live marker geometry remain client acceptance checks. There is no continuous full quest-catalogue scan for every nameplate.
