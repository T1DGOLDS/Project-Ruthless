# Active Forever journal

The active load-on-demand manifest loads WowheadRecords.lua, built from factual public Wowhead Forever journal records. Provenance, current counts and explicit gaps: main addon Assets/DungeonJournal/SOURCES.md. Native verified floor maps and previously bundled map art retain their separate provenance. The historical Records.lua and Source directory below are preserved but not loaded into the Forever catalog; TBC dungeons and raids are excluded.

# Bundled dungeon records

Derived from installed AtlasLoot Forever 1.60.1 data.lua and data-tbc.lua (GPL v2), originally https://github.com/Hoizame/AtlasLootClassic. Records retain GPL terms; see included license. Normal/heroic/raid numeric loot entries are preserved separately. UI scripts, libraries and animations are not copied. Tables are reference data, not a guarantee of live Forever loot completeness. Original data source and export script are retained under Source/ for reproducibility.
